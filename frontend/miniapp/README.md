# 小程序与 H5 前端

本目录用于初始化 uni-app 和 Vue 3 项目，包含用户页面与农户中心，分别构建微信小程序和 H5。

- 微信小程序必须能在微信开发者工具中运行演示。
- H5 提供浏览器访问入口，与微信端共用后端；平台登录、绑定和分享需要分别适配。
- 已确认正常打开先到首页、游客浏览公开内容、分享链接直达对应详情；底部为首页、分类、助农、购物车、我的，AI 从首页卡片和“我的”进入。
- 游客可查看 AI 入口和介绍，发送消息需登录，首版不设个人每日固定次数；具体控费参数仍待确认。
- 具体页面布局、未登录个人页及购物车的显示仍待细化。
- 业务接口依据 `../../docs/api/`，需求依据 `../../docs/requirements/`。
