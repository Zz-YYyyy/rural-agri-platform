# 小程序与 H5 前端

本目录为 uni-app、Vue 3、TypeScript 工程，分别构建微信小程序和 H5。已提供五个底部导航页、AI 介绍页及账号密码注册、登录、会话恢复和退出。商品、交易与农户中心仍为页面骨架，页面不会伪造业务数据或调用收费模型。

- 微信小程序必须能在微信开发者工具中运行演示。
- H5 提供浏览器访问入口，与微信端共用后端；平台登录、绑定和分享需要分别适配。
- 已确认正常打开先到首页、游客浏览公开内容、分享链接直达对应详情；底部为首页、分类、助农、购物车、我的，AI 从首页卡片和“我的”进入。
- 游客可查看 AI 入口和介绍，发送消息需登录，首版不设个人每日固定次数；具体控费参数仍待确认。
- 当前布局为可调整的页面骨架，后续按模块接入真实接口。
- 业务接口依据 [接口文档](../../docs/api/接口文档.md)，需求依据 [需求文档](../../docs/requirements/需求文档.md)。

## 账号功能

- 游客正常打开仍进入首页，可自由切换五个底部导航；“我的”提供登录及注册入口。
- 注册只提交 `username`、`password`、`nickname`，成功后回到登录页，不自动登录、不授予农户或管理员身份。账号去首尾空格并转小写，密码保留原样；密码长度同时受字符数和 72 个 UTF-8 字节限制。
- 登录调用 `POST /api/v1/auth/login`，随后调用 `GET /api/v1/me` 确认当前身份；本机只保存 token 和失效时间，不保存密码或可信角色资料。重启后仍须重新请求 `/me`，不会依据旧缓存显示农户或管理员身份。
- token 两小时失效，不做自动刷新。失效或接口返回 401 后清理当前凭证；旧请求的 401 不会清除后来登录的新凭证。暂时断网或服务异常时保留未到期凭证，显示重试入口，且不阻止游客浏览。
- 退出调用 `POST /api/v1/auth/logout`，只退出当前会话。请求失败也清理本机凭证，界面会明确说明未能确认服务端会话撤销，不把断网当作服务端退出成功。
- 页面跳转只允许回到本项目已开放的页面，拒绝任意外部地址；微信端和 H5 共用上述账号密码流程，微信授权、手机号登录尚未接入。
- `src/api/auth.ts` 负责契约请求，`src/stores/session.ts` 负责凭证与当前身份，`src/services/session.ts` 负责恢复、验证及并发结果隔离，`src/utils/auth-form.ts` 负责表单校验与安全返回路径。运行真实账号流程需要后端及其 MySQL、Redis 正常可用。

在本目录运行（Node.js 22.12+，当前验证版本 24.14.1）：

```powershell
npm ci
npm run typecheck
npm run dev:h5
npm run dev:mp-weixin
npm run build:h5
npm run build:mp-weixin
```

H5 开发地址为 `http://127.0.0.1:5174`；微信开发版本输出为 `dist/dev/mp-weixin`，发布构建为 `dist/build/mp-weixin`。将 `.env.example` 复制为被忽略的 `.env.local` 后配置后端地址和本人微信 AppID；真实 AppID 仅写入构建输出，源码 manifest 保留空值。未配置时 DCloud 编译器在输出中使用 `touristappid`；编译成功不能替代微信开发者工具实际运行验收。

依赖版本遵循 [DCloud 官方 TypeScript 模板](https://github.com/dcloudio/uni-preset-vue/tree/vite-ts) 的稳定编译器组合并精确锁定。当前依赖审计仍有未处理项，开发服务只监听本机；完成兼容升级和复测前，不将本骨架视为可直接公网部署的版本。
