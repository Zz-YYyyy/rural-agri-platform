# 网页管理端

本目录用于初始化 Vue 3 管理端工程。首版使用统一管理员角色，负责审核、运营及订单管理，并记录重要操作日志。

人工审核仅保留首次农户入驻。商品发布修改和农户资料更新校验后直接生效，专题报名符合条件自动加入；管理端保留下架、禁用，以及退款复核和超时申请接手能力，不建立商品、资料或专题报名的逐条审核队列。

管理端的具体页面、操作权限和异常处理规则需在需求文档中进一步明确。

建议配套采用 Vite、Element Plus、Vue Router、Pinia、Axios 和 ECharts，具体依赖版本在初始化时固定。

需求与接口分别见 `../../docs/requirements/` 和 `../../docs/api/`。应用工程尚未初始化。
