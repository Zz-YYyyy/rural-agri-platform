# 网页管理端

Vue 3＋TypeScript＋Vite 网页管理端。已接入真实登录、当前账号查询、退出接口以及管理员路由守卫；保留八个管理模块的导航与页面骨架，没有虚构业务数据，业务管理操作仍待实现。

人工审核仅保留首次农户入驻。商品发布修改和农户资料更新校验后直接生效，专题报名符合条件自动加入；管理端保留下架、禁用，以及退款复核和超时申请接手能力，不建立商品、资料或专题报名的逐条审核队列。

从本目录运行（Node.js 20.19+ 或 22.12+，本轮验证使用 Node 24.14.1／npm 11.11.0）：

```powershell
npm ci
npm run dev
npm run typecheck
npm run build
```

开发地址 `http://127.0.0.1:5173`，端口占用时明确报错；`/api` 默认代理到 `http://127.0.0.1:8080`。按需复制 `.env.example` 为 `.env.local` 修改公共 API 地址与本地代理，禁止在 `VITE_*` 中配置任何密钥。生产构建在 `dist/`，部署须为 Vue Router history 路由配置页面回退，并将 `/api` 交给后端。

固定依赖与锁文件随源码管理，后续安装使用 `npm ci`。

## 登录与权限

- 未登录访问管理模块会转到 `/login`，登录成功返回原模块；返回地址只接受现有管理模块路径。
- 登录使用 `POST /api/v1/auth/login`，随后调用 `GET /api/v1/me` 确认当前账号 `isAdmin=true` 才展示管理页面。普通用户会被拒绝并尝试退出刚建立的会话。
- 刷新及受保护路由切换均通过 `/me` 重新验证；本机 `sessionStorage` 只保存凭证和到期时间，不持久化或信任角色。验证服务暂不可用时停留登录页，可手动重新验证。
- 退出调用 `POST /api/v1/auth/logout` 并清除本机凭证。服务端退出失败会明确提示“本机已清除、服务端退出未确认”，不声称已完成服务端撤销。
- 本工程不创建默认管理员、不提供管理端注册或自动提权。管理员账号须按后端部署说明显式准备；所有实际业务权限由后端验证。
- HTTP 401 仅在失败请求仍对应当前凭证时清除会话，旧请求不清除后续登录的新凭证；失败保留状态码、业务码、traceId 与限流重试时间，不自动重试写操作。密码不写入浏览器存储。

本轮已通过类型检查、生产构建及 Edge 浏览器的模拟接口验证，覆盖权限拒绝、刷新恢复、依赖异常重试、退出失败提示和延迟 401 隔离等 15 组检查。模拟响应仅用于独立浏览器验证，不随应用发布。另以全新、无接口拦截的浏览器会话完成真实后端 6 组联调：普通账号拒绝、临时管理员登录、导航复验、刷新恢复、退出撤销及退出后路由拦截；退出后的原 token 再请求 `/me` 返回 401。临时账号只用于本轮联调，不属于默认管理员。完整基础设施及验收结果以统一验证记录为准。
