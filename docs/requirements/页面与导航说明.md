# 页面与导航说明

状态：导航、启动规则及专题报名、参与管理、草稿发布、基础表单与发布时点校验、计划时长、普通编辑、公开预告、自然／提前结束历史、整体隐藏与解除的基本规则已确认，其他页面内容和部分访问细节仍在讨论。最近整理日期：2026-11-19。

本文帮助后续开发者理解产品形态。已确认的业务规则以 [需求正文](需求文档.md) 为准；首页启动、分享进入、五个底部入口和 AI 入口见 FR-UI-001、FR-UI-002，专题报名条件、时间、详情主体、商品参与及内容管理见 FR-PROMO-013 至 FR-PROMO-033。其余布局、按钮、字段与未决访问条件仍需细化，不直接据此生成全部页面。

## 1 启动与登录

**已确认**：正常打开先到首页，游客可浏览有效公开的产品、农户、产地、故事、助农信息和专题；由分享进入时直接打开对应详情，个人操作再引导登录。登录有效时使用当前账号状态，个人数据按身份与归属校验。

**已确认的 AI 边界**：游客可以查看入口和静态介绍，发送 AI 消息需要登录；首版不设个人每日固定次数，其他费用控制继续生效。具体见 FR-AI-006、FR-AI-007。

**仍待细化**：未登录购物车和“我的”的显示方式、登录后返回原页面及保留规格数量。AI 完整历史的保存时长和删除策略也仍待确认。

统一账号密码和微信绑定已经确认，具体注册、绑定冲突、解绑与账号找回规则见 Q-AUTH-001。

## 2 五个主入口

**已确认**：底部导航为下表五项，顺序固定为首页、分类、助农、购物车、我的。表内具体内容与布局仍需逐页细化。

| 入口 | 主要展示与操作 |
| --- | --- |

| 分类 | 切换产品分类，按地区或其他条件查找商品 |

助农展示按 FR-PROMO-002 区分农户主动信息与管理员组织的专题：前者说明单个农户的推广需要并关联已有商品，后者集中组织符合条件的参与商品。发布信息成功后出现在助农页，不表示已经加入专题或取得首页推荐位；除下述已确认的专题详情主体外，其他具体布局和页面拆分仍为设计方案。

专题详情的主体依据 FR-PROMO-015、D-066：顶部背景帮助用户了解专题，参与商品列表是主要内容，商品产地和所属农户随商品展示，用户可进入对应商品详情或农户主页。专题不自动赋予优惠或另一套价格，不增加采购意向表单；选规格、加购物车和下单均沿用既有购物链路。浏览专题、报名加入及加购物车不预占库存，实际预占仍由有效创建订单触发。其他商品卡片字段、多规格价格的表示方式、分页、排序与筛选尚未确定，不将本次主体选择扩展成完整视觉稿。

专题的开始、结束与报名窗口按 FR-PROMO-014，具体农户页面规则见下文。依据 FR-PROMO-016 至 FR-PROMO-018，同一农户可有多个参与商品，同一商品也可分别参加多个进行中且符合条件的专题；农户成功退出某个选定专题后，该商品不再在该专题参与列表展示，其他专题中的有效参与不受影响。参与、退出与重报均不生成另一套商品价格或库存。

专题缺货展示按 FR-PROMO-019、D-070：商品所有当前可选规格均无可售库存时，仍可报名并继续展示，标注“暂时缺货”，用户可按原登录与沟通规则咨询；不要求先补货才可报名，购买仍须校验所选规格的实际可售库存。该规则不放宽商品正常上架、农户经营权限、专题条件、时间及管理限制，也不代表咨询已预订或保证供货。

主动下架暂隐藏与管理员移出的差异见 FR-PROMO-020、FR-PROMO-021，具体农户和管理端要求见下文。本段主动下架的“暂隐藏”仅确定商品不在专题参与列表展示；商品自身详情与旧来源新咨询仍按各自规则及未决边界处理，不套用独立助农信息旧链接限制。商品资料变化后不匹配进行中专题时，另按 FR-PROMO-033 暂隐藏并保留参与，不能显示成商品被下架、主动退出或管理员移出；符合条件的其他专题及既有订单咨询不受该处置影响。

专题草稿按 FR-PROMO-022、D-073 仅在管理端可见，不能在用户端或农户端查看、报名；即使草稿填写的开始时间已经到达，也不自动公开或开放报名，所填结束时间经过也不自动变成公开历史。已发布但尚未开始且当前允许公开的专题按 FR-PROMO-025、D-076 提供预告，用户和农户可查看介绍及原开始／结束时间，标注“即将开始”；不提前报名、不预占参与名额、不自动加入商品。具体预告列表位置仍待设计。

专题公开页面按 FR-PROMO-025 至 FR-PROMO-027、D-076 至 D-078 区分业务阶段与整体访问限制：

| 有效阶段或限制 | 列表、详情与报名要求 |
| --- | --- |
| 尚未发布的草稿 | 用户及农户端不公开，不报名；到达所填开始或结束时间也不自动发布 |
| 已发布、未开始且允许公开 | 显示即将开始预告、介绍及原起止时间，不能提前报名 |
| 已发布、处于计划时间内、未有效结束且允许公开 | 可显示进行中专题和当前合规商品，接受满足全部资格的报名；单凭计划时间未过不能判定可报名 |
| 已自然结束且允许公开 | 退出进行中列表，旧详情标已结束，提供当前允许的历史入口，停止报名和进行中参与恢复 |
| 已提前结束且允许公开 | 即使原截止未到，也退出进行中列表并标已提前结束，仅提供当前允许的历史入口，不能重新开放报名 |
| 任一已发布阶段存在整体隐藏 | 退出所有公开列表，旧链接提示暂不可用、不返回原介绍或参与列表，禁止报名；开始或到期不自动解除隐藏 |

整体隐藏只能由管理员手动解除。解除时先尊重已有效结束的事实，再判断是否未开始或仍进行；已结束仅恢复允许的历史，未结束才按时间恢复预告或当前合规的进行中展示。解除不补偿隐藏时长、不清除其他限制、不恢复已退出或单独移出的参与，页面不能把“解除隐藏成功”展示成所有商品或活动均已恢复。

已发布专题自然到期按 FR-PROMO-024、D-075 保留公开历史，管理员提前结束按 FR-PROMO-026、D-077 保留相应历史：有效结束后退出正在进行列表，不再报名、重报或恢复进行中参与；旧详情保留背景，分别明确标注“已结束”或“已提前结束”。历史范围的判断时点，自然结束使用原截止时刻，提前结束使用首次有效实际结束时刻，原计划时间仍保留。以该时点未退出、未被移除的当前参与为准；此前退出或移出后已在有效结束前合规重报的，按当前这一轮参与判断。商品详情和农户主页入口分别检查当前公开权限，专题整体隐藏时也不能凭保留历史返回原内容。

不匹配暂隐藏的结束历史及结束后资料变化留待后续设计，不阻塞已确认主流程；不能直接套用下表的农户主动下架历史结论。

| 有效结束时的参与情况 | 自然／提前结束后历史页面的要求 |
| --- | --- |
| 结束时仍保留参与，未退出且未被管理员移出 | 保留在历史商品范围内；按商品与农户当前公开权限分别提供可访问入口，实际购买仍使用原商品当前有效规格、价格与库存 |
| 结束时仅因农户主动下架暂隐藏，未退出且未被管理员移出 | 同样保留在历史范围内；当前受限的入口不能绕过权限开放，之后商品或农户可公开时可显示对应历史入口，不需要也不能重新报名已结束专题 |
| 结束时已经退出或已被管理员移出，尚未重新形成有效参与 | 不因之后商品上架或管理员解除移出限制而补入本专题历史商品范围，也不能借此重新开启已结束专题 |

历史范围保留与正在进行的参与展示是不同概念。结束时暂隐藏的商品后来可公开时出现历史入口，不表示恢复活动、延长原时间或生成新参与。自然／提前结束都不下架原商品、不改变订单、咨询和交易库存；用户经允许的商品或农户入口继续操作时仍遵守目标当前规则。提前结束后的原截止任务不能再结束一次、改写来源时间或重新收集历史商品。当前不可公开对象的占位样式、历史字段快照／实时策略及其他未决管理细节仍待设计，整体隐藏导致历史页暂不可用的规则已确认，不能继续把它列为未决或为了保留历史绕过限制。

全平台强制下架或禁用的专题联动、商品／专题隐藏或其他受限期间及结束后退出、整体隐藏期间说明编辑和提前结束、未开始取消、不匹配隐藏与结束历史的交叉、字典变更、已结束说明更正及统计仍待确认。进行中商品产地／分类变化不匹配时按 FR-PROMO-033 暂隐藏保留，不再把该处理整体列为未决。发布后原时间条件仍固定，专题不套用独立助农信息的 30 天／7 天规则。

用户浏览助农信息不创建订单或咨询；只有用户执行相应动作才进入原业务流程，个人操作需要登录。首版通过直接购买与异步站内留言承接需求，不提供独立采购意向入口，见 FR-COMM-002。助农信息不提供另一套价格、库存或交易表单，商品购买仍遵守现有上下架与选规格规则。缺货、农户主动下架暂隐藏及正常结束历史访问见 FR-PROMO-010 至 FR-PROMO-012；管理员处置／经营权限变化及下架与结束叠加的详情优先级仍待 Q-PROMO-001。

助农信息基础展示按 FR-PROMO-004、FR-PROMO-005：一条信息只关联一个商品，复用其图片、产地、价格及库存，用户仍可选择商品原有规格。供货时间或买家类型未填写时只表示未提供，具体空项样式待设计，不能显示成随时有货或农户已承诺某类供货条件。

有效推广时间按 FR-PROMO-006：农户自选截止且最长为首次有效发布后 30×24 小时，到达截止即退出正在推广列表并保留记录。页面使用服务端期限与状态，不能依赖客户端倒计时重新延长；到期不下架原商品或取消既有业务。正常结束历史公开原内容并标已结束，关闭旧条新增咨询，允许跳转当前可公开的商品或农户主页，见 FR-PROMO-012。

助农信息公开页面的状态要求（FR-PROMO-010 至 FR-PROMO-012，页面布局尚待设计）：

| 场景 | 列表与旧链接展示 | 新操作 |
| --- | --- | --- |
| 正常上架、有效经营权限、推广未结束，全部可选规格无可售库存 | 仍可列出和查看，明确标注暂时缺货；部分规格有库存时按规格展示可售情况 | 登录后可发送咨询留言，但不代表预订或保证供货；购买须满足所选规格实际库存 |
| 农户主动下架，推广尚未结束 | 退出公开列表，旧链接仅提示暂不可用，不向普通访问者返回原推广正文 | 不接受从该条新发咨询，后端同时拒绝旧页面提交；原期限继续、名额仍占用 |
| 商品重新上架合规且原推广未结束 | 恢复原条展示，继续原截止，缺货则标暂时缺货 | 按当前业务权限提供入口，不显示为新增一次推广或延长 30 天 |
| 正常结束，未叠加尚待明确的访问限制 | 不进入正在推广列表；旧链接显示原内容及推广已结束 | 不从旧条新增咨询；可跳转当前可公开的商品或农户主页，按目标页面权限继续对接 |

隐藏中到期仍按原截止结束，重新上架不能恢复推广。商品仍下架时到期后的历史详情显示优先级、已结束历史的关联商品后来主动下架，以及管理员强制下架或禁用联动仍待 Q-PROMO-001；不能把表中一般历史访问规则直接覆盖这些未决情况。既有留言保留，原参与者按各自业务权限继续处理，不等于在公共详情展示沟通内容或参与者资料；历史商品资料采用快照或当前值也仍待设计。

图文故事与产地介绍的维护分工见 FR-CONTENT-001，页面不能把农户发布的故事显示成平台核验认证。普通公开页面与农户自己的推广反馈入口分开，FR-PROMO-003 未授权向所有访客公开私有反馈或咨询者身份。

商品详情示例：同一苹果商品展示农户手工添加的“3斤装”和“5斤装”，选中后显示该行每份价格与可售份数；只有一种时使用“默认规格”。“3斤装”30 元一份，买两份商品款 60 元，扣该规格两份库存。基础必填与选填信息见 FR-PRODUCT-003，数量语义见 FR-PRODUCT-004；按钮位置、图片上限等仍待设计。

储存方式、应季月份未填时，不强制补齐，不自动显示成“耐储存”或“全年应季”。具体空值文案或是否隐藏空项在页面设计时确定。

两类商品下架均使新购买不可用：购物车中的下架商品不能结算成新单，AI 不继续提供可购买推荐。通过旧分享链接或旧商品页面进入也不能绕过后端限制。已有订单的付款资格需按 FR-PRODUCT-005、FR-PRODUCT-006 判断，不能与商品的新购状态混为一谈；下架详情的具体展示样式仍待设计。

购买评价已确认是整笔订单的整体体验（FR-REVIEW-001），公开集中展示在农户主页，商品详情只提供“查看农户评价”入口（FR-REVIEW-005）。入口应指向当前商品所属农户的评价区域或列表，不在商品详情内嵌评价预览或按商品重新生成评分。具体跳转与页面拆分可在设计时确定，不改变公开位置的选择。

农户主页展示允许公开的单条评价星级、用户选填的文字／图片及已有农户回复，并说明这是整体购物体验；游客可以浏览。买家统一显示“匿名用户”和默认头像，农户回复仍标明农户身份，不提供买家实名切换或个人主页入口；公开响应不携带买家真实昵称、头像及订单号、收件人、手机号、详细收货地址等私有字段，见 FR-REVIEW-006。列表排序及农户汇总评分仍待 Q-REVIEW-001，不用一个未经确认的平均分代替已确认的单条星级。

公开列表按 FR-REVIEW-007 处理隐藏：评价被隐藏后其回复也不独立公开；只隐藏回复时原评价仍可展示。恢复评价不清除回复自身的隐藏限制。买家或农户自己的订单页面如何展示被隐藏内容与处理原因仍待确认，不能将公开隐藏理解为物理删除或自动剥夺原私有订单权限。

| P-ORDER | 订单详情 | 商品、金额、订单保存的收货资料、买家备注、农户、状态、模拟发货与退款进度；有效未付款可改收货信息，付款后固定；备注创建后固定；待收货保留手动确认并显示自动确认期限，完成后区分确认来源 |

| P-REFUND | 退款详情 | 申请与审核记录、24 小时复核截止提示、有效复核入口、两个待处理阶段的撤回、超时等待提示和最终结果；具体布局待定 |

已确认的操作边界：未付款订单可取消，创建后 30 分钟未支付自动关闭并返还库存；发货前可申请整单模拟退款。等待农户审核、拒绝后的有效 24 小时复核窗口及管理员待处理阶段均暂停发货。两个待处理阶段可撤回；窗口到期未复核、有效撤回或管理员不支持退款时恢复发货权限。超过 48 小时未处理只触发超时待办，不自动退款，见 FR-REFUND-001 至 FR-REFUND-006。

前端可依据后端有效状态展示操作与截止时间，不能仅按自己计算的倒计时恢复发货或允许过期复核。重复申请限制、材料和通知位置等剩余问题见 Q-REFUND-001。

客户端倒计时只是展示，不能自行把订单标记为支付成功或已取消。支付结果需要服务端确认，参见 FR-ORDER-002。

FR-ORDER-003 已确认下单锁价：原订单 86 元、后续同样商品的新订单变为 96 元，其他条件仍满足时原订单仍在原 30 分钟有效期内按 86 元支付，符合退款条件时也按原实付处理。确认页到提交之间变价的提示与确认交互仍待 Q-ORDER-001。

商品下架后的订单页面行为已确认，具体布局仍待设计：

| 下架场景 | P-ORDERS、P-ORDER、P-MOCK-PAY 的业务要求 |
| --- | --- |
| 农户主动下架 | 原有效未付款订单仍显示原金额、原剩余付款时间，并保留允许的支付和取消操作；不要仅因商品详情不可新购就隐藏旧单付款能力 |
| 管理员强制下架 | 相关未付款整单关闭，展示关闭状态及原因，不提供继续支付；保留全部原订单明细及金额，未付款关闭不显示成退款成功 |
| 两类下架前已经付款 | 按现有订单及退款阶段展示履约或售后；退款暂停发货不能因下架解除 |

页面重新读取服务端结果后更新按钮；即使旧页面仍显示支付按钮，后端也不能让已经受强制下架限制或已经关闭的订单付款。管理员强制下架关闭会返还整单全部占用，不由客户端逐行处理。账号禁用、规格移除等其他条件继续待确认。

订单资料与模拟物流的已确认页面行为：

| 场景 | 展示或操作要求 |
| --- | --- |
| 下单收货资料与备注 | 提供四项收货信息及整单选填备注；备注不填也可下单，说明文字不修改结构化订单内容 |
| 修改有效未付款订单收货资料 | 进入目标订单后主动修改，显示本次保存仅作用于该订单；保存成功使用后端最新结果，不改变金额或原剩余付款时间 |
| 已付款、已关闭或已过期 | 不再提供有效改址操作，旧页面提交也应按后端状态失败；不因地址簿变化更新订单展示 |
| 下单后的备注 | 保留原文或空状态，无补填／修改操作；改地址表单不能连带覆盖备注 |
| 模拟发货成功 | 订单详情显示模拟承运方、系统生成的演示单号、发货节点及时间和待收货状态，清楚标注模拟属性 |
| 用户有效确认收货 | 增加收货节点与时间，记录用户手动确认来源，订单完成；不能在刚生成单号时提前展示成已收货 |
| 发货满 7 天仍待收货 | 后端自动完成后展示“系统自动确认”及实际完成时间，不能显示为用户主动确认或真实物流签收 |

详细规则见 FR-ORDER-004、FR-ORDER-005、FR-SHIP-002、FR-ORDER-006。自动确认期限从有效模拟发货时间加 7×24 小时计算，前端只展示服务端提供的期限与状态，不能倒计时归零就自行写成完成；已手动完成后不再显示一个仍会改写结果的待自动确认倒计时。具体时间文案和布局在页面设计时确定，发货资料纠正仍未决定。

评价页面的已确认边界：显示本次订单摘要和一组整单星级／文字／图片输入，不按商品或规格逐项显示多组评分表单。未选择星级不能提交；文字与图片均可留空，图片最多 3 张。不能预填五星来代表用户已经作出选择，也不能从确认收货页面自动提交评价。

订单完成与是否评价分别展示。买家可以暂不评价，系统不将“未评价”显示成默认好评；已完成但没有评价是合法状态。重复提交后显示同一有效结果，不能增加该订单的评价条数，也不能覆盖原内容。提交成功前可调整未提交输入，成功后依据 FR-REVIEW-003 固定星级、文字和图片。

买家订单详情可查看自己的原评价和已有农户回复，公开集中农户主页不影响这种按归属查询的私有入口；被管理员隐藏内容的私有展示方式另待 Q-REVIEW-001。买家不在回复下面继续追问，不把评价页变成多轮会话，不提供改评、自行删除／撤下或追加评价操作。隐藏后不能显示为可以重新评价，普通站内留言仍按原沟通模块使用。

首次评价期限按 FR-REVIEW-008：实际完成后 30×24 小时内，尚未评价且满足条件时显示填写入口与截止时间；达到截止后关闭入口并说明评价期限已过，不显示默认好评。用户在期限内打开表单但到期后提交时，以后端校验为准，保留前端输入不延长资格。已有效评价后显示原结果，到期不将其误标为“未评价已过期”；农户的一次回复不受这 30 天窗口限制。

## 6 异步站内留言页面

首版采用“直接购买＋异步站内留言”，见 FR-COMM-001、FR-COMM-002。普通购买和现有商品规格、可售数量能够满足的批量购买，均进入原商品与订单流程，不以先咨询或提交采购表单为购买条件。特殊供货、包装等问题通过文字留言沟通，农户稍后查看和回复，不要求双方同时在线，也不承诺实时送达或即时答复。

| 页面标识 | 页面 | 展示内容与主要操作 |
| --- | --- | --- |
| P-MESSAGES | 消息中心 | 咨询回复、订单相关消息入口和未读状态，具体通知类型待定 |
| P-CONVERSATION | 留言会话 | 用户与农户的异步文字留言、回复、商品上下文、发送入口与未读状态；双方只能查看自己参与的会话，不要求同时在线 |

批量购买例子：假设苹果有“5斤装”规格、可售库存至少 40 份，且满足其他下单条件，用户计划购买 200 斤时可选择 40 份，按原流程下单并支付；如果想询问是否支持其他包装或后续补货，可先发送站内文字留言，农户稍后回复。留言本身不预占库存、不创建订单、不自动付款，也不承诺特殊价格、预订成功或保证供货。最终下单仍依据当时有效的规格、价格、库存与购买权限。

首版不为批量问题增加议价、报价、承接或成交状态，也不增加实时聊天或咨询必填联系方式；不能把普通留言页重新设计成隐含的采购意向表单。站内发送规则、长度限制、会话归并与消息通知等细节仍需后续设计。推广暂隐藏或正常结束时，关闭的是从该推广来源新增咨询的能力；既有留言继续保留，参与者按原权限访问与处理，不因停止推广而自动终止既有沟通。

| P-FARM-PROMO-STATS | 我的推广反馈 | 首版展示本人权限范围内的浏览、咨询反馈；统计周期、次数人数、来源归属、空态及更新时效后续确定 |

已确认一个账号对应一个农户，保留普通购物能力。首次入驻需管理员审核，通过后使用一个农户中心；商品和资料修改不再逐条审核。个人中心如何呈现两个业务入口仍按页面讨论方案确认。

专题报名页面按 FR-PROMO-013、FR-PROMO-014 及 FR-PROMO-025 至 FR-PROMO-027，分别对应 D-064、D-065 及 D-076 至 D-078，表达以下已确认边界：

| 条件或阶段 | 页面与操作要求 |
| --- | --- |
| 管理员尚未发布的草稿 | 仅管理端可见，农户端不显示为可查看或可报名专题；不能因为开始时间到达就开放报名 |
| 产地条件 | 可不限，或选择一个省、市、县区节点；按商品产地匹配所选节点本身及下级，不以农户经营地区代替，不提供多地区任一匹配 |
| 分类条件 | 可不限，或选择一个平台分类节点；按商品分类匹配节点本身及下级，不以农户主营品类代替，不提供多分类任一匹配 |
| 产地和分类均设置限制 | 两项必须同时满足；仅一项有限制时仍需满足该项；两项均不限时仍校验其他报名条件 |
| 已发布专题开始前 | 当前允许公开时可看预告及原起止时间，不开放报名，不提供提前报名后自动加入的流程 |
| 从原开始时刻起、原结束时刻之前 | 时间窗口只是必要条件；专题须已发布、尚未有效提前结束、未整体隐藏且其他限制允许，再校验经营权限、本人正常上架商品、产地分类与防重复要求，成功即加入，不等待人工审核 |
| 已自然结束或已提前结束 | 停止报名、重报及进行中参与恢复；旧页面不能以原截止尚未到达或倒计时未刷新继续提交 |
| 专题整体临时隐藏 | 农户端无公开列表和原详情内容，旧链接暂不可用；隐藏有效期间不能报名，已有参与保留，不显示为已退出或必须重新报名 |
| 管理员解除专题整体隐藏 | 有效结束事实优先：已结束仅可按当前权限看历史，未结束时按时间恢复预告或当前合规的进行中展示与报名；不自动恢复个人已退出或被移出的参与 |

匹配按 FR-PROMO-031、FR-PROMO-032、D-082、D-083：两项限制同时满足，节点自身也匹配，以有效标识和隶属关系判断，不用名称或宽泛上级猜测更窄范围。字典来源、层深和节点变更留待后续设计，不固定全平台分类层数。

开始和结束时间由管理员设置，计划报名窗口为“开始包含、结束不含”，即 `原开始时间 ≤ 服务端当前时间 < 原结束时间`；满足该区间仍须排除有效提前结束、整体隐藏及其他限制。发布后原起止和产地／分类限制固定，未开始也不能普通修改，见 FR-PROMO-023。客户端倒计时或按钮不替代后端当前判断；报名失败不能显示已加入，成功也不代表首页推荐或特殊交易待遇。自然／提前结束后能访问历史不等于恢复报名资格。

发布时的阶段由 FR-PROMO-029、D-080 补充：若计划开始已经过去或恰到且计划结束仍未来到，实际发布成功后即可按当前条件报名，但不能把原开始到实际发布之间显示为已公开、已接受报名或已存在参与；若原开始在未来则仍按预告处理。原结束已到的草稿不能作为已结束专题直接发布，农户不能从草稿或迟到的发布页面提前取得参与资格。

商品参与管理按 FR-PROMO-016 至 FR-PROMO-018，分别对应 D-067 至 D-069。页面应让农户明确当前操作的是哪个商品与哪个专题，不把一个商品的全部专题参与合并成一次退出操作。

| 操作或场景 | 已确认页面行为与业务边界 |
| --- | --- |
| 同一农户报名多个商品 | 每次选择一个商品报名，可逐次把多个符合条件的本人商品加入同一专题；不设固定的每农户参与商品数量上限，不增加一次批量选择多个商品的报名流程 |
| 同专题同商品重复报名 | 同时最多一份有效参与；已有有效参与时，不因重复点击、重新进入页面或选择另一规格产生第二份有效参与，规格不单独作为报名商品计数 |
| 同一商品参加多个进行中专题 | 分别按目标专题的条件、报名时段和管理限制校验；有效加入新专题不替换原专题参与，也不要求先退出原专题；各处共用原商品价格、规格和库存，不建立专题专属库存 |
| 农户主动退出 | 选择本人商品要退出的具体专题；有效退出后该商品不再在该专题参与列表展示，退出记录保留；原商品上下架、其他专题中的有效参与和已有订单、咨询不受影响 |
| 退出后重新报名 | 目标专题仍在计划报名窗口内、未有效结束且未整体隐藏，当前商品与农户符合条件且无管理限制时，可立即重报，无额外冷却期；校验通过后才重新展示，不能凭历史成功或解除整体隐藏跳过当前校验 |

例如，假设本人苹果和梨商品均符合“本地丰收”专题当前条件，农户可分两次报名，使两个商品同时参与；苹果还可独立报名符合条件的另一专题。苹果有效退出“本地丰收”后，只从该专题参与列表移除，梨及苹果在另一专题的有效参与仍保留，已有订单和咨询继续按各自规则处理。苹果重报“本地丰收”时重新校验当前资格，不等待独立助农信息的 7 天重发期。

以上是商品与专题参与关系的业务说明，不规定底层记录采用复用行、追加行或其他物理存储方式。退出历史须保留；重报后的排序与统计如何反映历史仍待确认，不能默认重报必然置顶、清空历史或增加新的推广成果。

缺货、主动下架与专题管理员移出的页面联动按 FR-PROMO-019 至 FR-PROMO-021，分别对应 D-070 至 D-072：

| 场景 | 页面表现与操作边界 |
| --- | --- |
| 商品正常上架、所有当前可选规格无可售库存，其他资格满足 | 仍允许报名和继续展示，明确标暂时缺货，可按原规则咨询；选规格和购买继续使用真实库存，不把专题展示当作可立即下单或供货保证 |
| 农户主动下架商品 | 该商品在各个进行中专题里的当前参与暂隐藏，保留原参与；不能显示为已经主动退出、已经被管理员移出或需要重新报名，原专题期限继续计算 |
| 农户重新上架，目标专题仍进行中、当前条件满足且无管理限制 | 仅恢复因农户主动下架暂隐藏且仍保留的原参与，无需重新报名，不重新计时或延长专题；全部可选规格仍缺货时也可恢复并标暂时缺货 |
| 参与已主动退出、已被管理员移出，或目标专题已经自然／提前结束 | 商品重新上架和专题解除整体隐藏不能使这些参与恢复为正在进行的有效参与；历史范围和入口按 FR-PROMO-024、FR-PROMO-026 判断，不将历史可见理解为恢复活动 |
| 管理员从指定专题移出该商品 | 该商品不在该专题当前参与列表展示，移出原因与历史记录保留；农户不能自行重新报名，也不能通过下架再上架、换规格或旧报名页面绕过该项限制 |
| 管理员已解除该商品在指定专题的移出限制 | 不自动恢复展示；农户须在该专题报名窗口内重新报名，仍需满足当前条件且没有其他有效限制，成功后重新展示；解除不改变原专题时间，也不解除商品、账号或其他专题的限制 |
| 商品产地／分类改后不符合某进行中专题 | 按 FR-PROMO-033 暂隐藏该专题中的商品并保留参与，不显示为已退出、已移出或必须重新报名；逐个专题判断，其他仍符合条件的专题不受该处置影响 |
| 后来商品资料符合且专题仍进行、原参与保留、所有资格限制允许 | 恢复原参与，无需重报、不延长时间、不创建重复参与；不要求改回原值，只要当前资料符合固定条件即可 |
| 资料已匹配但仍整体隐藏、原参与已退出／移出或有其他限制 | 不自动恢复公开，也不提供绕过限制的恢复按钮；合法解除整体隐藏后仍按当时资格校验，已结束不能恢复进行中，不匹配隐藏的结束历史另待确认 |

商品暂隐藏或恢复不重新创建商品价格、库存或订单。管理员移出与解除仅作用于指定商品在指定专题的参与限制，不改变原商品上下架，不影响其他专题的有效参与、已有订单和咨询；不得把专题移出显示成全平台商品强制下架或退款。农户主动下架本身对新购买及旧订单的已确认规则仍按 FR-PRODUCT-005 执行，不因专题参与保留而放宽。

单地区／单分类及进行中不匹配暂隐藏按 FR-PROMO-031 至 FR-PROMO-033 实现主流程，字典、历史和其他交叉细节留待后续设计。资格联动不下架商品、不改其他仍符合专题或既有订单咨询与库存，不增加审核或其他权限；缺货规则不变。

助农信息、故事维护及反馈入口分别依据 FR-PROMO-002、FR-CONTENT-001、FR-PROMO-003，表中 P 标识用于讨论能力归属，不代表已经确定独立路由或每个按钮。发布成功与校验失败需有明确反馈，不能显示“等待管理员审核”；农户不能通过替换农户或内容标识维护他人的内容，也不能读取其他农户的私有统计。

发布表单补充规则见 FR-PROMO-004 至 FR-PROMO-006、FR-PROMO-010：页面应区分供货时间与推广截止时间，前者选填、后者必填；一个商品单选不限制该商品原有规格，正常上架且经营权限有效时缺货也可发布，不能把库存大于零作为选品必需条件。缺少必填或截止时间无效时需提示修正，发布前预览时间不作为有效发布时间，后端仍按实际发布校验。正常结束后的新发布入口依据 FR-PROMO-009 重新校验，不能以编辑或恢复旧条代替。

发布后管理依据 FR-PROMO-007 至 FR-PROMO-009：

| 当前情况 | 页面行为与后端要求 |
| --- | --- |
| 本人信息仍在推广且权限有效 | 允许编辑标题、说明、供货时间和买家类型，必填约束保留、选填可清空；关联商品和原发布时间／截止只展示不改动 |
| 主动提前结束 | 操作只结束本条推广，退出正在推广列表并保留记录；显示原截止及有效结束结果，不下架原商品、不终止既有留言或取消订单 |
| 已自然到期或主动结束 | 不再提供有效编辑或农户恢复原条；展示正常结束方式与等待期，公共历史按 FR-PROMO-012；具体私有历史列表样式待设计 |
| 农户主动下架导致暂隐藏且尚未结束 | 说明暂不公开但期限仍在继续；不能以隐藏为由重设计时、补偿时长或开放第二条，重新上架合规且未结束才恢复展示；隐藏期间编辑／主动结束入口权限另待确认 |
| 同商品尚有未结束推广，包括主动下架暂隐藏记录 | 不提供有效的第二条新发布操作，后端同样防止并发或旧页面绕过，不按规格重复放行 |
| 正常结束后未满 7 天 | 显示尚需等待或最早可再次发布时间，不允许有效重发；自然到期按原截止、主动结束按首次成功结束时间起算 |
| 已满 7 天且其他资格有效 | 可由农户主动创建新推广记录，旧条保留；新条仍自选截止且最长 30 天，不将原内容恢复或把旧轮次反馈当成新轮次成果 |

页面采用服务端返回的有效状态与资格；进入编辑页后若已经结束，提交也不能成功，客户端倒计时到零不能自行授予重发权限。结束成功后的重复操作或旧到期任务不能改变第一次有效结束时间。农户主动下架暂隐藏也照常到期，从原截止起算 7 天，重新上架不能恢复已结束条。独立改期／延期、删除、管理员处置／禁用及恢复、暂隐藏期间维护权限，以及下架与结束叠加的历史详情优先级仍待 Q-PROMO-001，不默认新增相关按钮。

首版推广反馈仅覆盖浏览、咨询，农户查看本人权限范围内反馈，管理员查看平台汇总，见 FR-PROMO-003、FR-COMM-002。浏览、打开咨询入口、实际发送留言是不同动作；咨询按人数、会话还是有效留言计数，以及去重、统计周期和来源归因，尚需定义。界面不能直接显示“已帮助增收”或把全部模拟销售额作为某条信息的推广成果，未完成统计或加载失败也不能先约定显示为零。

农户回复按 FR-REVIEW-004：仅订单所属农户可对已经存在的评价提交一条普通文字；发布后固定，不显示修改、自行删除／撤下或再次回复入口，后端同样拒绝绕过。公开评价下标注农户回复并与匿名买家原文区分，不能显示成平台退款裁定。按 FR-REVIEW-008 不另设回复期限，但已有回复被隐藏也不能重发；隐藏评价能否首次回复仍待确认。是否另外提供独立评价管理列表仍待页面设计，不因可回复就新增一套审核待办。

库存维护已确认采用“补货／减少可售”的增减语义（FR-INV-002）。页面展示具体规格和当前可售份数，填写本次增减量；提交成功后使用服务端返回的最新数量，失败时提示数量或权限问题。不能让农户通过商品编辑把包含订单占用的总量直接改掉。独立页面还是弹窗、是否填写原因及记录查询入口仍待设计。

农户主动下架的操作说明应表达“停止新下单，已有有效订单仍可付款”；销售订单仍按原规则处理。管理员强制下架需与普通下架区分，商品编辑或补货不能清除该限制；恢复权限尚未确认，不默认开放一个可绕过限制的上架按钮。

## 8 管理端页面范围

管理员在单独的 Vue 3 网页管理端工作，不把管理员工作台放入农户中心。

| 候选页面组 | 已确认能力与待细化内容 |
| --- | --- |
| 登录与工作台 | 登录方式、待办摘要、统计口径和快捷入口 |
| 用户与农户 | 列表、资料、首次入驻审核、账号状态；恢复和存量订单处理权限仍待定 |
| 商品与分类 | 分类维护、商品查看及强制下架；强制下架关闭相关未付款整单并返还全部占用，已付款不自动退款；不设逐条商品审核，恢复权限仍待定 |
| 内容与推广 | 维护产地及专题草稿，四项基础资料补齐并按生效时点校验后发布，封面选填；开始已过但尚未结束可立即进行，未来开始则预告，发布后时间条件固定；可提前结束、整体隐藏及手动解除；可移出指定商品或解除限制但不自动恢复参与；农户故事自行维护，无逐条内容审核，交叉权限仍待定 |
| 推广反馈 | 管理员查看平台浏览、咨询反馈汇总；筛选、统计周期和来源归属后续设计，不将汇总入口开放给普通农户 |
| 订单与售后 | 订单查询、模拟交易与退款记录、拒绝后的复核；超过 48 小时的待办和农户超时申请人工接手；具体页面及其他人工处理边界待定 |
| 评价与回复管理 | 管理员隐藏／恢复评价或回复、填写原因、查看操作记录；不修改原内容，不设逐条预审；具体列表筛选和页面拆分待设计 |
| 基础配置 | 轮播图、推荐内容或其他运营设置的具体范围 |
| 操作日志 | 操作者、对象、时间、动作和结果等记录与查询 |

首版只有统一管理员角色，仍需逐个动作定义权限和数据可见范围，不能把“管理员”理解为可以不留记录地任意修改所有业务状态。

专题创建、普通编辑及管理操作依据 FR-PROMO-022、FR-PROMO-023、FR-PROMO-026 至 FR-PROMO-030，分别对应 D-073、D-074、D-077 至 D-081：

| 管理场景 | 已确认页面能力与限制 |
| --- | --- |
| 保存草稿 | 可保存尚未补齐的信息，仅管理端可见；保存成功不等于公开或开放报名，也不要求所有发布必填项已填完，具体草稿字段、校验及管理员间归属权限仍待设计 |
| 正式发布基础表单 | 标题、普通文字介绍、开始时间和结束时间必填；封面选填，无图用统一默认；产地与分类各可不限或选择一个节点含其下级，所选节点自身也包含；不新增富文本详情编辑器，具体输入参数仍待设计 |
| 主动发布 | 管理员补齐资料后主动发布，无二次审批；服务端以发布生效时刻校验计划开始早于计划结束、计划结束晚于当前时间，失败保留草稿且不公开；不会因草稿时间经过自动发布或重算原起止 |
| 计划开始已过或恰到，计划结束仍未来到 | 允许发布成功后立即进行，从实际成功发布才接受报名，不补写此前公开展示、报名或参与，不把原开始改为发布时间 |
| 计划开始在未来 | 发布成功后按原时间公开预告，到开始后且状态允许才报名 |
| 已到或超过草稿原结束时间 | 拒绝直接发布为过期历史，先调整未发布草稿时间再发布；迟到请求不能按打开页面或点击时的旧时间通过 |
| 计划时长设置 | 不设统一时长上限，必须填写明确有限的起止并通过发布校验；按原结束减原开始计算计划时长，不按发布时间重算，未采用 90 天上限；发布后仍不能延期或重开 |
| 已发布但尚未结束 | 允许修改标题、介绍等说明性内容；从发布起时间及产地／分类限制固定，未开始也不能改；整体隐藏期间是否可编辑说明仍待确认，不能从普通编辑权限直接推定 |
| 希望改时间或报名条件 | 另建专题并按其发布和报名规则处理，原专题和参与不自动迁移，不把新专题当作原专题的延期或自动恢复 |
| 专题已经自然／提前结束 | 普通编辑不能重开、延长报名或恢复进行中；可按已确认权限整体隐藏／解除历史页，结束后说明更正仍待确认 |
| 正常进行中提前结束 | 管理员记录原因提交；保留原计划起止，另记首次有效实际结束时刻、来源和操作者，成功后立即停止报名并标已提前结束；不能显示恢复进行中入口 |
| 已发布专题整体临时隐藏 | 适用于预告中、进行中及已结束，保留参与与内部历史；公共列表及旧链接不公开原内容、不报名；原计时继续，隐藏本身不表示提前结束 |
| 管理员手动解除整体隐藏 | 先核对自然／提前结束事实，再按时间和当前权限恢复预告、合规进行中或仅历史；不补时、不清其他限制，不复活退出或移出参与，开始到期不会自动解除 |

草稿保存、有效发布和公开预告分别遵守 FR-PROMO-022、FR-PROMO-025，不能把公开预告延伸为公开草稿预览。2026-11-19 确认的基础表单、发布时点校验和计划时长按 FR-PROMO-028 至 FR-PROMO-030 执行；具体表单分组、草稿最少字段／路由／归属、文字长度、图片上传限制、默认资产和时间精度仍待设计。普通编辑字段限制由后端执行，标题／介绍变化不修改原参与、时间或条件，也不新增复制或续期按钮；独立助农信息的 30 天／7 天规则不变。

提前结束、整体隐藏与解除分别依据 FR-PROMO-026、FR-PROMO-027、D-077、D-078，不能将它们合并成一个可任意切换的进行中／结束／公开按钮。提前结束的原因须记录，但长度和对外可见范围未定；隐藏／解除原因是否必填及操作记录可见范围仍待确认。重复操作或原截止任务不能覆盖首次有效提前结束事实，解除隐藏不能误清后续有效限制。隐藏期间说明编辑、农户退出、管理员提前结束、未开始取消及已结束说明更正仍未确认；这些管理操作均不改变商品、其他专题、已有订单、咨询或交易库存。

专题参与管理依据 FR-PROMO-021、D-072：管理员操作时应能明确识别目标专题和商品，移出需记录原因并保留历史，农户在限制有效期间不能自行重报。解除只取消该商品在该专题的移出限制，页面不能把结果显示为已经恢复参与；后续由农户在报名期内按当前资格重新报名。移出和解除不下架原商品，不连带移除其他专题参与，也不取消已有订单或咨询；原因的具体展示对象、页面布局及其他管理状态细节仍待设计。

评价管理依据 FR-REVIEW-007 展示目标内容及其自身隐藏状态，并区分回复自身隐藏与因父评价隐藏而不可公开。恢复父评价时不能暗示会解除回复单独的隐藏限制；隐藏／恢复需填写原因并保留结果记录，不提供改星级、编辑图文或删除后重新评价的入口。处理原因是否向买家或农户展示继续待确认。

商品强制下架的页面说明需明确会关闭相关未付款整单，其中其他仍上架商品也一并退出该订单；保留管理动作与订单关闭结果用于查询。已付款订单依原规则继续处理。具体确认交互、结果展示和批量操作是否提供在页面设计时决定，不把本轮选择扩展为任意取消已付款订单的管理权限。
