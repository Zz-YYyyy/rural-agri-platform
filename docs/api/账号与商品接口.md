# 账号、农户与商品接口

版本：V1 设计契约，2026-11-20。尚无运行中的 HTTP 服务。字段的完整类型、必填性、枚举、长度与示例维护在 [本模块契约源](分模块契约/账号与商品.json)，合并导入入口见 [接口文档](接口文档.md)。数据库依据见 [字段字典](../database/数据库字段字典.md) 和 [实现说明](../database/数据库实现与迁移说明.md)。

## 公共规则

- 本文路径包含 `/api/v1`。普通 JSON 请求使用 `Content-Type: application/json`；MEMBER、FARMER、ADMIN 请求需 `Authorization: Bearer <accessToken>`。FARMER 必须有当前账号对应的有效经营身份，ADMIN 校验独立管理员标识；不能只看 URL 或前端入口。
- 成功均为 HTTP 200，包络为 `code/message/data/traceId`；分页使用 `page/pageSize`，默认 1/20、最大每页 100，结果为 `items/total/page/pageSize`。所有 ID 是正整数字符串，金额是精确两位小数字符串，时间为 UTC ISO 8601 毫秒字符串。
- 登录态本轮采用 2 小时 access JWT 与 Redis jti 会话，不发 refresh token；退出撤销当前会话，失效后重新登录。管理员和普通用户用同一凭证格式；初始化管理员走后续专用演示种子流程，没有公开提权接口。
- 请求只接收 schema 声明的字段，拒绝多余属性；服务端执行 trim、资源归属、目录有效性及数据归属校验。普通公开接口不返回手机号、密码哈希、微信内部标识或后台管理元数据。
- `Idempotency-Key` 只用于标注的接口。入驻、人工库存和重要管理动作以数据库唯一业务键/日志恢复结果；商品和地址新增因没有持久请求键，仅采用公共 Redis 请求防重窗口。后者如遇崩溃导致结果不明，先查询本人列表核对，不宣称严格一次。重要交易类接口的幂等规则见交易模块。
- 不可见的私有目标统一 404；已登录但缺少所需角色为 403。手机号公开范围尚未确定，因此公共 DTO 不包含该字段；首次入驻的管理员审核按既有审核目的读取提交资料。

## 各接口的权限、前置条件和业务效果

### registerAccount：注册平台账号

`POST /api/v1/auth/register` · PUBLIC

检查规范化用户名唯一和密码UTF-8字节限制；只创建普通ACTIVE账号，禁止客户端写isAdmin或农户状态。成功不自动登录，客户端继续调用登录。用户名冲突返回409，重复注册不重置密码。

关键错误：`USERNAME_EXISTS`（409）：登录名已被使用；`RATE_LIMITED`（429）：注册过于频繁。

追踪：FR-AUTH-001；验收：AC-AUTH-001。

### loginAccount：账号密码登录

`POST /api/v1/auth/login` · PUBLIC

校验BCrypt密码与账号有效状态；签发2小时access JWT并在Redis登记jti会话，不发refreshToken。失败统一返回凭证错误，避免区分不存在账号和错误密码；管理员使用同一登录协议。

关键错误：`INVALID_CREDENTIALS`（401）：账号或密码错误；`ACCOUNT_DISABLED`（403）：账号已禁用；`RATE_LIMITED`（429）：登录尝试过于频繁；`DEPENDENCY_UNAVAILABLE`（503）：会话依赖不可用。

追踪：FR-AUTH-001、FR-ROLE-001；验收：AC-AUTH-001。

### loginWechat：已绑定微信快捷登录

`POST /api/v1/auth/wechat/login` · PUBLIC

仅用于本项目配置的小程序AppID。后端兑换一次性code并按app_id+open_id查绑定；已绑定且账号正常才签发会话。未绑定返回WECHAT_NOT_BOUND，引导注册/登录平台账号后绑定；不自动创建微信账号。

关键错误：`WECHAT_CODE_INVALID`（400）：code无效或已使用；`WECHAT_NOT_BOUND`（409）：该微信身份尚未绑定平台账号；`ACCOUNT_DISABLED`（403）：绑定账号被禁用；`DEPENDENCY_UNAVAILABLE`（503）：微信或会话服务暂不可用。

追踪：FR-AUTH-001；验收：AC-AUTH-001。

### bindWechatIdentity：首次绑定当前微信身份

`POST /api/v1/me/wechat-binding` · MEMBER

已登录账号提交code，服务端兑换身份后按唯一微信标识绑定。相同微信已经绑定本人则返回原关系；绑定到他人返回冲突。当前账号在此AppID没有绑定时可首次绑定；已有不同绑定时涉及数量/换绑策略，返回POLICY_PENDING且不修改数据。只返回绑定事实，不输出openId、unionId或sessionKey。

关键错误：`WECHAT_BINDING_CONFLICT`（409）：微信身份已绑定其他账号；`WECHAT_CODE_INVALID`（400）：code无效或已使用；`POLICY_PENDING`（503）：该业务分支尚未确定，暂不开放。

追踪：FR-AUTH-001；验收：AC-AUTH-001。

### getWechatBindingState：读取本人微信绑定状态

`GET /api/v1/me/wechat-binding` · MEMBER

仅查询当前账号在服务端配置的小程序AppID中的绑定事实，未绑定返回bound=false且省略boundAt；不能指定其他userId或appId，也不返回openId、unionId或sessionKey。

追踪：FR-AUTH-001；验收：AC-AUTH-001。

### logoutCurrentSession：退出当前会话

`POST /api/v1/auth/logout` · MEMBER

根据当前JWT的jti撤销Redis会话；不退出其他设备。已撤销会话重试视为退出成功；不得仅让客户端删除token。会话存储不可用返回503，前端可清除本机token但不能宣称服务端已成功撤销。

关键错误：`DEPENDENCY_UNAVAILABLE`（503）：会话撤销未确认完成。

追踪：FR-AUTH-001；验收：AC-AUTH-001。

### getCurrentAccount：读取当前账号与入口身份

`GET /api/v1/me` · MEMBER

从认证主体读取本人资料与独立管理员/农户能力；无农户身份时省略farmerId/farmerStatus。不得接受客户端userId替代当前身份。

追踪：FR-AUTH-001、FR-FARM-002；验收：AC-AUTH-001、AC-FARM-001。

### updateCurrentProfile：修改本人昵称头像

`PUT /api/v1/me/profile` · MEMBER

全量替换昵称和选填头像，avatarKey为null时恢复默认。只接受本人可用头像key；不能更改username、密码、isAdmin、账号状态或农户身份。相同目标值重试自然幂等。

关键错误：`RESOURCE_KEY_INVALID`（400）：头像资源无效或不属于当前用户。

追踪：FR-AUTH-001；验收：AC-AUTH-001。

### listMyAddresses：读取本人收货地址

`GET /api/v1/me/addresses` · MEMBER

仅查询本人，空列表返回[]。

追踪：FR-AUTH-001、FR-ORDER-004；验收：AC-AUTH-001。

### createMyAddress：新增本人收货地址

`POST /api/v1/me/addresses` · MEMBER

新增前校验有效县区节点；设为默认时锁账号并取消旧默认。普通新增采用公共Redis防重窗口，故障不确定时先刷新地址列表核对，不承诺跨存储崩溃的绝对一次。 防重缓存保留24小时，以userId+operationId+Idempotency-Key定位并保存规范化请求摘要和结果ID；窗口内同键异内容409，结果不明不得自动更换键重试。

参数：`Idempotency-Key`；参数位置、必填与默认值见机器契约。

关键错误：`REGION_INVALID`（400）：地区无效或不是可用县区。

追踪：FR-AUTH-001、FR-ORDER-004；验收：AC-AUTH-001。

### updateMyAddress：修改本人收货地址

`PUT /api/v1/me/addresses/{addressId}` · MEMBER

核对本人归属后全量替换地址；默认切换与本次修改同事务。改动不传播到已有订单，重复相同值自然幂等。

参数：`addressId`；参数位置、必填与默认值见机器契约。

关键错误：`REGION_INVALID`（400）：地区无效或不是可用县区。

追踪：FR-AUTH-001、FR-ORDER-004；验收：AC-AUTH-001。

### deleteMyAddress：删除本人地址簿记录

`DELETE /api/v1/me/addresses/{addressId}` · MEMBER

只删除本人地址簿记录，不删除订单快照。不存在或已删除的本人目标按无副作用处理；不能因ID存在于他人账户而删除。删除默认地址后允许暂时无默认项，不自动修改旧订单。

参数：`addressId`；参数位置、必填与默认值见机器契约。

追踪：FR-AUTH-001、FR-ORDER-004；验收：AC-AUTH-001。

### listRegionChildren：读取地区下一级

`GET /api/v1/regions` · PUBLIC

parentId省略返回所有可选省级节点；有值则返回该节点的有效直接下级。按sortOrder、id升序；不依赖用户定位、不限定单一县。

参数：`parentId`；参数位置、必填与默认值见机器契约。

关键错误：`RESOURCE_UNAVAILABLE`（404）：目标不存在或不允许当前访问者查看。

追踪：FR-REGION-001；验收：AC-UI-001。

### getCategoryTree：读取可选商品分类树

`GET /api/v1/categories` · PUBLIC

返回ACTIVE节点组成的根分类树，按sortOrder、id升序，过滤无有效祖先的节点。不限制全平台固定层数；服务端维护无环目录。

追踪：FR-PRODUCT-001、FR-PROMO-032；验收：AC-UI-001。

### submitFarmerApplication：提交首次农户入驻申请

`POST /api/v1/me/farmer-applications` · MEMBER

只收四项必填和简介/封面。锁当前账号，检查尚无农户身份和活动申请；Idempotency-Key持久化为farmer_application.request_id，同键同资料返回原申请，不刷新提交时间，同键异资料409。已有退回记录后的全新重提、待审修改撤回未决，返回POLICY_PENDING；首次正常申请可执行。

参数：`Idempotency-Key`；参数位置、必填与默认值见机器契约。

关键错误：`STATE_CONFLICT`（409）：当前业务状态不允许该操作；`IDEMPOTENCY_CONFLICT`（409）：同一幂等键对应不同请求内容；`POLICY_PENDING`（503）：该业务分支尚未确定，暂不开放。

追踪：FR-FARM-001、FR-FARM-002、FR-FARM-003；验收：AC-FARM-002、AC-FARM-003、AC-FARM-004、AC-FARM-007。

### listMyFarmerApplications：查看本人入驻申请记录

`GET /api/v1/me/farmer-applications` · MEMBER

按submittedAt、id倒序；只返回当前账号提交的资料和审核结果，不混入其他账号。

参数：`page`、`pageSize`；参数位置、必填与默认值见机器契约。

追踪：FR-FARM-001；验收：AC-FARM-004、AC-FARM-007。

### getOwnFarmerProfile：读取本人经营资料

`GET /api/v1/farmer/profile` · FARMER

只读取当前账号唯一农户身份的经营资料。联系手机号仅在本人经营维护与合法首次审核范围返回，不出现在公开农户详情。

关键错误：`FARMER_REQUIRED`（403）：当前账号没有有效农户经营权限。

追踪：FR-FARM-002、FR-FARM-003、FR-FARM-004；验收：AC-FARM-001、AC-FARM-005。

### updateOwnFarmerProfile：修改本人经营资料与固定运费

`PUT /api/v1/farmer/profile` · FARMER

校验四项必填、选填资料和非负两位运费后直接生效，不人工复审。只修改本户，不能更改userId、approvedApplicationId或经营状态；新运费只影响新建订单，普通重复替换自然幂等。

关键错误：`FARMER_REQUIRED`（403）：当前账号没有有效农户经营权限；`RESOURCE_KEY_INVALID`（400）：封面资源不可用。

追踪：FR-FARM-004、FR-SHIP-001、FR-ORDER-003；验收：AC-FARM-005、AC-FARM-006。

### listPublicFarmers：浏览可公开农户

`GET /api/v1/farmers` · PUBLIC

仅返回当前允许公开的有效经营农户与有效账号，按id倒序。地区筛选包含所选节点及其下级。手机号不在公共投影中；复杂经营禁用历史访问规则不由此列表推导。

参数：`page`、`pageSize`、`regionId`、`keyword`；参数位置、必填与默认值见机器契约。

追踪：FR-FARM-001、FR-REGION-001、FR-CONTENT-001；验收：AC-UI-001。

### getPublicFarmer：读取农户公开主页

`GET /api/v1/farmers/{farmerId}` · PUBLIC

返回名称、产地、主营品类、简介、故事及公开商品/评价入口所需计数；不返回联系手机号、所属账号ID或申请审核材料。不可公开的目标统一404。农户评价独立调用评价列表接口，不把整单评分拆给商品。 接受可选X-Visitor-Id随机UUID；有有效登录时按账号归属并忽略该值，无有效标识仍可浏览但不记事件。成功详情读取按直接来源与UTC 30分钟桶生成去重VIEW，登录农户查看自家内容不记本人推广浏览；不采集设备指纹。无效可选登录凭证按游客处理，统计遵守助农模块口径。

参数：`farmerId`、`X-Visitor-Id`；参数位置、必填与默认值见机器契约。

关键错误：`RESOURCE_UNAVAILABLE`（404）：目标不存在或不允许当前访问者查看。

追踪：FR-FARM-001、FR-CONTENT-001、FR-REVIEW-005、FR-PROMO-003；验收：AC-UI-001。

### adjustOwnSkuStock：按增减份数调整本人规格库存

`POST /api/v1/farmer/products/{productId}/skus/{skuId}/stock-adjustments` · FARMER

Idempotency-Key 持久化为 stock_log.business_key 的 ADJUST:{userId}:{key}；同键必须为同一 SKU、delta 和原因，重试返回原流水。锁规格后读取当前可售量 A，并计算仍可能返还的占用 R：该 SKU 的 OCCUPIED 明细中，所属订单处于 PENDING_PAYMENT 或 PENDING_SHIPMENT 的数量合计。退款处理中及已经超时但尚未关闭的订单仍计入，已发货或已完成订单不计入。

使用宽整数计算，要求 `A + delta >= 0` 且 `A + delta + R <= 2147483647`（INT_MAX），为旧订单取消、超时关闭或成功退款保留返还容量，不能仅因补货后的可售量未超上限就放行。调整事务使用 READ COMMITTED，在取得 SKU 行锁后重新查询 R，不复用旧快照；下单、关闭、成功退款和发货等改变 A 或 R 的事务共用 SKU 行锁，多规格按 ID 升序，库存、明细／订单状态与流水同事务提交。库存调整与 MANUAL_ADJUST 流水同成同败，不修改订单占用；管理限制也不会因补货解除。

例如仍可能返还 1 份时，不允许将可售补到 INT_MAX，最多补到 INT_MAX - 1；该订单随后取消或退款可正常返还 1 份，不因先前补货而溢出。

参数：`productId`、`skuId`、`Idempotency-Key`；参数位置、必填与默认值见机器契约。

关键错误：`IDEMPOTENCY_CONFLICT`（409）：同一幂等键对应不同请求内容；`INSUFFICIENT_STOCK`（409）：减少数量超过当前可售份数；`STOCK_RANGE_EXCEEDED`（400）：调整后可售库存与仍可能返还的占用合计超出库存整数范围。

追踪：FR-INV-002、FR-INV-001、FR-PRODUCT-006；验收：AC-INV-008、AC-INV-009、AC-INV-010、AC-INV-012、AC-INV-013、AC-PRODUCT-015。

## 示例：农户发布商品与增减库存

发布请求 `POST /api/v1/farmer/products`，携带当前农户凭证及新的 `Idempotency-Key`：

```json
{
  "name": "应季柑橘",
  "categoryId": "12",
  "originRegionId": "10103",
  "introduction": "本地果园当季采摘。",
  "imageKeys": [
    "uploads/1/product/example.jpg"
  ],
  "seasonMonths": [
    10,
    11,
    12
  ],
  "skus": [
    {
      "specName": "3斤装",
      "price": "29.90",
      "initialStock": 100
    }
  ]
}
```

创建成功返回 `ProductOwnerView`，例如服务端分配 `productId="101"`、`skuId="1001"`。补货走 `POST /api/v1/farmer/products/101/skus/1001/stock-adjustments`，新业务使用新幂等键，网络重试复用原键：

```json
{
  "delta": 20,
  "reason": "演示补货"
}
```

原可售 100 份且没有并发变化时，首次补货后为 120 份，重试不增加到 140 份。商品基本资料编辑不能提交 `availableStock`；价格更改仅影响后来创建的订单。

## 尚未开放的业务分支

| 事项 | 当前处理边界 | 待确认编号 |
| --- | --- | --- |
| 微信解绑、换绑、多绑定 | 首次绑定与同身份重试可用；已有不同绑定时返回 POLICY_PENDING，不覆盖他人或本人的旧关系 | Q-AUTH-001 |
| 入驻退回后重提、待审修改或撤回 | 保留查看原记录；不提供修改/撤回端点，新重提分支暂不执行 | Q-FARM-001 |
| 账号与经营身份禁用／恢复 | 这里只读基本状态；具体存量订单、退款和咨询权限未定，不生成可执行的新管理端点 | Q-FARM-001、Q-ADMIN-001 |
| 管理强制下架后的解除／恢复 | 强制下架已设计；没有农户自解限或管理端一键恢复接口 | Q-PRODUCT-001、Q-ADMIN-001 |
| 已有商品的规格新增、停用、删除 | 新商品创建时可填完整多规格；既有规格可改名称、价格、排序和增减库存，不物理删除历史引用 | Q-PRODUCT-001 |
| 地区／分类树迁移、删除与停用联动 | 地区由演示数据初始化；分类只提供新增、名称和排序维护，不擅自迁移已有节点或改变被引用状态 | Q-CONTENT-001、Q-CAMPAIGN-001 |
| 密码修改、找回及其他设备退出 | 本轮仅固定当前会话退出；未设计的账号恢复能力不会凭字段存在自动启用 | Q-AUTH-001 |

上述保留项不表示主流程无法实现，也不表示已彻底取消相关能力。正式实现前若决定开放，须补齐权限、接口与受影响需求；本轮没有修改数据库迁移。
