### removeCampaignParticipation

`POST /api/v1/admin/campaign-participations/{participationId}/remove`：从专题移出商品并限制重报。权限：ADMIN。

| 参数 | 位置 | 类型 | 必填 | 校验与默认值 | 含义 |
| --- | --- | --- | --- | --- | --- |
| `participationId` | path | Id | 是 | 最长=19；匹配=^[1-9][0-9]{0,18}$ | 目标资源ID，服务端校验归属与可访问性 |
| `Idempotency-Key` | header | string | 是 | 最短=16；最长=64；匹配=^[A-Za-z0-9_-]+$ | 一次业务提交的幂等键；重试复用，同键不同内容返回409。持久化或24小时缓存范围以各操作说明为准。 |

请求体：`application/json`，`CampaignRemoveRequest`。

成功 HTTP 200，data：`CampaignParticipation`。

主要业务错误：409 `STATE_CONFLICT`：当前阶段不允许该操作，请刷新详情；409 `VERSION_CONFLICT`：版本或参与轮次已变化，请刷新后重试；409 `IDEMPOTENCY_CONFLICT`：同一个幂等键不能对应不同的目标或内容；503 `POLICY_PENDING`：该交叉情形的业务规则尚待补齐，当前不开放此操作。

未决分支：['Q-CAMPAIGN-001：结束后及整体隐藏期间的进一步参与管理范围未定。']。
