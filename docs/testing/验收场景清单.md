# 验收场景清单

状态：根据已确认需求制定的验收设计，基础账号已开始实际执行，其他业务按阶段验收。最近更新：2026-11-20。

本文件让后续开发者明确预期行为。表中的编号用于关联需求与未来测试，不代表测试已经通过。基础工程已有独立构建与 HTTP 检查，见 [基础工程验证记录](基础工程验证记录.md)；账号密码流程的实际覆盖见 [账号与基础设施验证记录](账号与基础设施验证记录.md)；含微信绑定的完整账号场景及其他业务仍未全部通过。

按 2026-11-19 用户调整，后续优先验证可演示的主要流程和必要的权限、交易一致性、AI 控费；不为普通增删改查穷举细碎组合。已有场景保留追踪，不把所有低优先级未决边界当作开始开发的门槛。

明确标为“后续扩展／不属首版”的条目只保留原编号供范围变更追踪，不计入首版必须执行的验收，也不将旧编号改作其他功能。
