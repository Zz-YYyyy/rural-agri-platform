## 依赖审计

审计使用 npm 官方 registry 的安全接口，不把镜像站不支持审计时返回的错误当成零问题。2026-11-20 本次管理端审计为 0 项，结果仅针对当时的固定依赖树和公告库。

uni-app 官方稳定模板配套依赖仍有已知审计项，不能宣称安全检查全部通过。主要涉及 Vite 5.2.8 开发服务文件访问与 Windows 编辑器启动链、vue-i18n 9／@intlify 转义相关 XSS、Vue server-renderer 3.4.21 的 SSR 问题，以及部分编译工具传递依赖。i18n 属于浏览器运行依赖，不能将全部问题归类为“仅开发工具”；本项目未启用 SSR，页面骨架也未接收不可信业务内容，但这不替代依赖修复。

当前开发服务只监听 127.0.0.1，暂不直接用于公网部署。未执行 `npm audit fix --force`、未绕过 DCloud 的精确 peer 版本要求；后续需要找到兼容的修复组合并重新验证 H5、微信及相关输入场景，再完成部署检查。这里记录实际依赖风险，不表示已经发生攻击。
